# Pathwise Frontend

React + TypeScript + Vite frontend for the Pathwise executive coaching simulation.

## Setup

```bash
cd frontend
pnpm install
```

## Development

```bash
pnpm dev
```

The frontend will run on `http://localhost:5173` and proxy API requests to the backend at `http://localhost:3000`.

## Build

```bash
pnpm build
```

## Features

- Audio recording via MediaRecorder API
- Real-time conversation display
- LLM provider selection (Claude, Gemini, Ollama)
- Session management
- Audio playback (placeholder)
